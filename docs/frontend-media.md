# 前端素材、媒体与作品星图

本文解释地址与资源生命周期的设计边界。全仓执行约束以根目录 `AGENTS.md` 为准；部署配置以 `docs/deploy.md` 为准。

## 地址属于谁

| 输入 | 托管方 | 处理入口 |
|------|--------|----------|
| Vite import 的 `/assets/bg-<hash>.webp`、开发 `/src/assets/*` | 前端站点 | 保留打包器提供的地址 |
| `public` 的 `/icons/*` 等静态素材 | 前端站点 | 保留前端路径 |
| API 返回的 `/thumbs/*`、`/uploads/*`、历史 `/images/*` | 媒体服务 | `utils/index.ts:getImageUrl` 补配置的媒体基址 |
| API 已返回的绝对媒体/镜像地址 | 地址所指服务 | 不再次拼接域名，保留查询参数 |
| 第三方图床、签名 URL、blob/data | 各自来源 | 保留原地址，不参与本站生产兜底 |

`isContentMediaPath` 是公开媒体目录的单一判定。不能根据“以 `/` 开头”“是图片扩展名”或“属于本站域名”认定它来自后端。新增公开媒体目录时同步服务端静态路由、共享判定、Vite 开发代理及契约测试。

`getRemoteFallbackUrl` 只为本站公开媒体生成生产同路径地址。前端域名和媒体域名独立配置，不从网站首页地址推导媒体域名。生产兜底常量定义在 `utils/index.ts`；开发贴图代理在 `vite.config.ts`，调整源站时两处一起核对。文档不再复制这些域名，避免成为另一份配置。

## 三条使用链路

- 普通图片：API `thumb` → `getImageUrl` → `MediaImage`。加载、失败与透明图状态保持可辨认；失败依次走调用方候选及本站媒体兜底。
- 详情大图：`ContentMedia` → `imageSource.ts` 来源探测与优先级 → `MediaImage`。来源未确定时保留加载反馈；失败回报具体地址，只影响相应来源，不把某张坏图持久化为整级不可用。
- 球面/星图贴图：API `thumb` 或打包底图 → `loadPlanetImage` → `planetImageSource` → `getImageUrl`。组件与 Three 场景均不得另写 URL 拼接或 `new Image` 加载分支。

普通 `<img>` 成功仅证明可展示。Canvas 读像素、导出快照和 WebGL 上传纹理还需要正确的跨域响应。`loadPlanetImage` 统一设置匿名 CORS、超时、取消和失败返回；`planetImageSource` 为本站跨域贴图区分缓存键，并保持第三方签名 URL 不变。HTTP 200 不能单独作为贴图成功的证据，还须确认响应类型、允许来源和真实渲染结果。

开发环境通过固定源站、固定公开目录的贴图代理解决 localhost 与生产 CORS 的差异。代理不转发身份凭据；不能为图省事改成任意 URL 代理，也不能把本地测试变成放宽生产白名单的理由。生产路径直接依赖媒体服务的 CORS 与 CDN 缓存配置，开发代理成功不能证明生产跨域成功。

## 星球与星图的职责

| 文件 | 拥有什么 | 不能承担什么 |
|------|----------|--------------|
| `ArtworkPlanet.vue` | 小球初始化、拖动/自转、可见性、贴片队列、进入星图 | API 分页、媒体域名判定、星图坐标算法 |
| `artworkPlanet.ts` | 作品抽取、贴图加载、球面图集绘制 | 页面状态、用户身份、详情来源探测策略 |
| `ArtworkUniverse.vue` | 展开/关闭阶段、焦点、背景 inert、阵列加载 | 全量常驻纹理、共享 URL 规则 |
| `artworkUniverse.ts` | 可复现随机坐标、碰撞与可见候选的纯计算 | DOM、HTTP、Three 渲染器 |
| `universeScene.ts` | 实例化节点、按可见范围加载贴图、选择/缩放、GPU 清理 | 业务列表请求、页面导航、动画阶段决策 |

`HomeView` 提供不断追加的作品列表，星球/星图按 id 消费。坐标在一次探索中稳定，新页不能挪动已显示作品；纯文本作品仍有节点。全量节点与可见贴图是两种资源，不能为“全作品”一次下载全部原图。并发、驻留数和像素大小以各自实现为准，调整时说明网络/GPU 成本并验证缩放拖动，不能默默解除上限。

## 初始化、取消与失败

星球初始化分成“建立可渲染场景”和“逐步替换作品”。装饰底图是可选输入：加载失败时仍应进入 ready、开启允许的自转并继续补图。WebGL 不可用才进入静态降级；两种失败不能混为同一条提前退出路径。

星图正常阶段为 `flight → unfold → marquee → collapse → map`，关闭从任一阶段进入 `closing`。跳过/关闭会使旧序列失效；每次异步等待后要检查版本或取消信号。不能让旧序列在关闭后重新写回阶段或创建场景。

资源由创建者负责结束：

- 星球在离屏、隐藏标签页、KeepAlive 停用和打开全屏星图时暂停；恢复统一经过 `updateAnimation`，避免重复帧循环。
- 星图 `setActive` 暂停渲染，`dispose` 释放资源；卸载需取消请求、帧循环和动画，移除监听器，释放几何体、材质、纹理、控制器与渲染器。
- Teleport 弹层要还原背景 inert 和先前焦点；关闭后验证首页仍可点击、滚动。背景锁滚沿用 CSS 声明与稳定滚动条槽位。
- 部分缩略图失败保留可交互的节点/失败反馈，不拖垮整个星图；取消后的结果不能进入队列、缓存或 GPU。
- 减少动效偏好应跳过空间演出，保持交互和加载反馈；不能通过全局移除 transform 破坏定位。

## 如何验证

自动回归入口：

| 用例 | 防止的回归 |
|------|------------|
| `utils/__tests__/mediaUrl.test.ts` | 空/非空媒体基址下，媒体归属、素材保留、解析幂等与禁止错误回退 |
| `utils/__tests__/planetImageSource.test.ts` | 贴图代理、缓存键、签名参数、底图归属与失败加载 |
| `components/__tests__/ArtworkPlanet.test.ts` | 底图失败后仍启动场景、加载并铺满首批作品 |
| `components/__tests__/ArtworkUniverse.test.ts` | 阶段推进、中途关闭、减少动效、搜索与清理 |
| `utils/__tests__/artworkUniverse.test.ts` | 随机分布、碰撞、追加稳定性与可见候选上限 |
| `components/__tests__/MediaImage.test.ts` | 加载反馈、逐级失败和前端素材不走媒体兜底 |

在仓库根运行类型和单测：

```sh
pnpm fe:typecheck
pnpm fe:test
```

验证生产构建必须设置非空媒体基址，不能只验默认同源开发页。例如在独立 PowerShell 会话里：

```powershell
$env:VITE_MEDIA_BASE_URL = 'https://media.example.invalid'
pnpm --filter ./packages/frontend run build-only
```

这里的 `.invalid` 域名刻意不提供媒体服务，仅验证打包与配置分支，不用于浏览器加载验收。真实预览应在独立终端使用部署配置的公开媒体基址重新构建，再运行 `pnpm --filter ./packages/frontend exec vite preview --host 127.0.0.1`。不得把真实密钥或整份 `.env` 写进验证记录；不要将临时环境变量留在用户的后续开发会话中。

真实浏览器按问题相关范围验证：

1. 确认访问的是开发页、生产构建预览还是线上部署；核对页面实际资源版本。前端素材从前端加载，API 媒体从配置源加载。
2. 初始空列表→作品到达→后续分页追加；图片在加载中有反馈，星球开始自转且作品逐步替换。暂停/恢复、拖动与键盘均可用。
3. 双击进入，演出中关闭/跳过，星图拖动/缩放/搜索/选作品，关闭后再次打开；不能残留遮罩、焦点锁或后台渲染。
4. 检查日→夜→日、桌面/手机与减少动效偏好中受此次改动影响的操作。
5. 对失败路径检查底图失败、单张缩略图失败与 WebGL 不可用；记录实际测试了哪些故障。模拟测试不能替代真实纹理渲染。
6. 生产媒体跨域问题在实际允许的前端 Origin 下核对 CORS/CDN；本地预览域名可能不在白名单，必须如实标注该限制。

自动工作流 `.github/workflows/frontend-check.yml` 负责类型、单测和带非空媒体基址的构建。它没有发布权限，也没有真实 WebGL/CORS 端到端覆盖；发布后还须在实际站点验收。
