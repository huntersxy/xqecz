# AI 创作与社区赞助

实现范围：`/studio` 工作台、`/characters` 角色库、`/ideas` 创意广场，以及既有后台中的「AI 创作管理」。后端仍是一个 Go 进程，任务执行器在进程内运行，不需要额外 Worker 服务。

## 首次配置

1. 部署新后端前备份数据库；启动时通过 GORM 自动迁移新增功能表。前端与后端应同时更新。本次开发与验收使用临时 SQLite 和 miniredis，没有启动连接生产数据库的后端。
2. `AI_IMAGE_DIR` 默认是项目根 `data/ai-private`，必须位于 `/uploads`、`/thumbs`、`/images` 的物理目录之外。不要为它添加静态路由、镜像或公开 CDN 挂载。
3. 首次启动生成 `AI_IMAGE_DIR/.encryption-key`。它用于 AES-256-GCM 加密站点和用户密钥，须与数据库、私有图片一起备份。丢失后不能解密已有配置与任务；服务会拒绝自动更换已有数据的加密密钥。Windows 部署应限制该目录的账户访问权限。
4. 管理员进入「AI 创作管理 → 供应商」，先选择与服务商文档一致的适配器，再填写完整接口 URL、模型和 API Key，然后启用。支持 OpenAI Images/兼容 Images（默认）、OpenAI Chat Completions、Gemini 原生协议和 Codex Responses；火山方舟、Gitee AI、SiliconFlow、Agnes AI、Grok 使用兼容 Images 适配器。默认示例为 `https://api.slomerex.xyz/v1/images/generations`、`gpt-image-2.5-sunburst-1K`，1024×1024、1 张、不传 quality、关闭参考图。
5. 设置每张站点额度、可选画质额度覆盖、允许尺寸、张数、参考图数量、超时和并发。只有供应商文档或真实测试支持时才开启相应参数。用户自备密钥只能选择这里批准的供应商，不能提交任意 URL。
6. 在「用户额度 / 账本」给用户发放额度并注明原因。站点额度是内部整数单位，不是供应商余额或货币。BYOK 不扣站点额度，但供应商仍可能收费。连通测试同样可能产生供应商费用。

可选环境变量仅用于**没有站点配置时首次导入**，后续以后台保存的配置为准：

```dotenv
AI_IMAGE_DIR=
AI_IMAGE_BASE_URL=
AI_IMAGE_API_KEY=
AI_IMAGE_MODEL=
```

`AI_IMAGE_BASE_URL` 是完整 `/v1/images/generations` 地址，不是域名根路径，首次导入按 OpenAI Images 适配器保存。Chat 适配器地址必须以 `/chat/completions` 结尾，Gemini 地址必须以 `:generateContent` 结尾，Codex Responses 地址必须以 `/responses` 结尾；Gemini 密钥通过受保护的 `x-goog-api-key` 请求头发送，不写进 URL。密钥不得设置为 `VITE_*` 或写入前端。空供应商配置不影响资源浏览与站点其它业务。

适配器选项是非密 JSON，仅按服务商文档填写。当前支持的通用选项包括 `watermark`、`optimize_prompt`、`negative_prompt`、`num_inference_steps`、`guidance_scale` 和 `output_format`；选项会随排队任务快照保存，不会覆盖认证或请求地址。

Codex Responses 适配器发送 `model`、`input` 和 `image_generation` 工具，默认输出 PNG；无参考图时使用文本 `input`，有参考图时使用多模态 `input`，当前每次任务限制为 1 张同步结果。

## 资源与创作流程

- 管理员先上传设定图，填写标题、用途、来源与授权，再发布素材。只能把自己上传的官方素材公开；不能通过素材管理将用户私人生成结果变成公开素材。
- 角色、组合、模板共用 `creative_resources`。有草稿、发布、归档、排序及版本检查。图片用 ID 关联，可被多个角色或组合复用。图像不可原地替换，更新时上传新资产，历史任务保留原图和快照。
- 模板支持固定文本、`{变量名}`、必填/默认值/选项/输入说明、实时预览、推荐组合与参数。变量值按字面替换，不递归展开；后端检查模板版本与变量。工作台由用户选择追加、插入或替换，以及是否带入推荐参考图和参数。
- 工作台保存会话名称、草稿、参考图与备注、参数、未确认提交键。任务独立持久化；关页后后台继续执行。私人结果可下载、作为参考图继续编辑、归档，或经明确公开确认发布到原有内容系统。
- 同一生成资产最多关联一条站内内容，复用审核、缩略图、媒体镜像、评论及点赞路径，带 `AIGC` 标签。私人图没有公共静态 URL；请求必须通过拥有者/管理员鉴权或已公开创意的范围检查。
- 创意投稿公开完整提示词、参考图、模型、参数和成功结果，投稿前须确认公开范围及参考图授权。投稿不扣额度，可在没有站点密钥时提交；供应商不可用时暂停赞助。
- 赞助只使用站点额度。事务锁住创意后预留赞助者额度并创建任务，同一创意最多一次成功实现。成功结果在创意详情公开，显示作者与赞助者；付额度不代表取得著作权。撤回/下架隐藏创意与成果，取消仍在排队的任务；已经发往供应商的请求继续核查与结算。

## 任务、额度与恢复

| 状态 | 处理 |
|---|---|
| queued | 已持久化并预留额度，可取消并释放 |
| running | 已开始执行，禁止自动重新请求 |
| succeeded | 结果落盘、资产入库并结算预留额度 |
| failed / cancelled | 确认未执行或拒绝时释放；人工确认计费时结算 |
| unknown | 超时、断线、部分结果或服务中断，保留已获取图片和预留额度 |

请求幂等键在草稿中保存后才提交；响应丢失时沿用同一个键确认已有任务。供应商调用不自动重试。管理员处理 `unknown` 前应在供应商侧核对实际执行与收费，填写 3–300 个字的核查依据后选择结算或释放（首尾空白不计入字数）。校验与提交失败的原因在核查弹层内显示，失败时保留说明和预留额度。管理员核查不会再次发起生图。

已下载并验证的结果在数据库结算前写私有恢复凭据 `.task-*-result.json`。运行中任务超过 10 分钟后，执行器读取有效凭据完成结算；没有凭据的旧任务转为 `unknown`，不会重发。凭据不是供应商异步查询协议，无法追回服务崩溃时尚未保存的远端结果。

账本记录发放、预留、结算、释放及操作人/说明，唯一键防重复扣款与结算。公开接口不会返回密钥、密文、私有文件路径或管理员核查备注。

## 数据与运行限制

新增 9 张表：`creative_resources`、`ai_provider_configs`、`ai_sessions`、`ai_generation_tasks`、`ai_assets`、`ai_quota_accounts`、`ai_quota_ledger`、`ai_ideas`、`ai_idea_events`。关联列表与不可变任务/创意快照保存在 JSON 中，避免为每种资源另建一套表。现有用户与内容表继续复用。

- 两路执行器；单供应商（包括其 BYOK 配置）并发 1–2。
- 每用户最多 2 个 queued/running/unknown 任务，每小时最多 20 次提交。
- 每任务最多 2 张输出、8 张参考图；参考图总计最多 32MB。
- 上传单图最多 20MB、4000 万像素；每日最多 50 个新资产，上传库每用户最多 512MB。接受实际可解码的 PNG/JPEG/WebP，按文件内容验证。
- 私人会话、任务与资产支持游标分页。资产归档保留文件与历史引用，不执行破坏性删除；需要定期规划存储容量与备份。
- 后台资源统一从“角色资源”管理名称、外观和图片；旧 `preset` 保留兼容，不再作为独立新建入口。角色、模板和旧组合的图片关系由 `utils/creativeResources.ts` 统一展开，生成时一起导入角色与图片。上传图片自动关联角色，授权提供“原创”“已获授权”预设；只需填写角色名称，高级链接标识留空自动生成。
- “公开素材”仅适用于当前管理员自己上传的设定图，来源与授权说明必填；生成结果通过工作台发布到站内。校验失败在弹窗内显示具体原因，不会公开文件。公开角色/模板关联的图片须同时允许用于生成与二创，避免资源可见却不能用于生成。
- 管理员免除站点生成/赞助额度扣减，由后端数据库角色判定；供应商能力和任务并发限制仍有效。公开创意价格仍表示普通用户的生成价格。
- `/admin/ai/users` 仅返回发放选择器需要的 ID/用户名；`/admin/ai/grants` 兼容单用户并支持 `user_ids` 或 `all_users`。批量发放在同一事务中写余额和账本，以每位用户的账本作为幂等凭据；全体用户重试复用首次目标快照，不给后来注册的用户追加旧批次。客户端未确认结果时保留原目标和幂等键。
- 工作台采用上方任务画廊、下方集中创作输入的布局，图片结果可逐张预览、下载、继续编辑或加入参考；当前会话与全部生成/赞助任务可分别筛选，复用提示词保留当前参考图与参数。桌面常用模型、尺寸、画质及数量直接可见，手机通过“生成设置”展开；生成方式和额度模式折叠在“更多”。输入 `@` 可选择按顺序编号的 `@图片N`；拖动图片或排序手柄改变参考图顺序，手机支持触摸拖曳，横向列表在边缘自动滚动，聚焦手柄后也可用左右方向键与 Home/End 排序。排序按目标位置插入并同步重编号已有引用，中间图片保持相对顺序；取消手势或放到列表外不改草稿，删除被引用图片时确认并移除对应引用。支持拖入、粘贴和上传 PNG/JPEG/WebP，统一校验模型参考图上限与单图 20MB；Ctrl/⌘+Enter 进入生成确认，输入法组字期间不提交。手机任务记录随整页滚动，输入区悬浮吸底；生成设置按需展开，也可收起输入区专注浏览。通过实际测量预留输入区高度，参考图及设置变化不会挡住最后一条记录；可视视口变化时避让软键盘，底部留出安全区，输入内容单独滚动且提交栏常显。上传请求随页面卸载取消，迟到结果不加入已切换的会话；提交待确认期间锁住草稿并继续使用原幂等键。
- 外部请求仅 HTTPS/443，拒绝内网/保留 IP、重定向、任意 BYOK 地址；结果下载不携带供应商 Authorization。部署机需能直接解析并连接供应商，不依赖系统 HTTP 代理。
- 推荐单实例运行。多实例必须共享同一私有目录和加密密钥，否则任务执行与结果访问不一致。未提供独立分布式文件存储。
- 角色详情使用稳定 Slug 并更新标题/描述；当前项目仍是 Hash SPA，没有增加服务端渲染或爬虫预渲染。

## 验证与供应商差异

真实调用已验证用户指定供应商的文生图链路：请求 1024×1024，返回 PNG 1254×1254，约 1.02MB。资产保留供应商实际返回的尺寸，不能把请求尺寸当成输出尺寸。

本机供应商域名解析为代理 Fake-IP（198.18 段），正常网络防护会拒绝该地址。一次性真实测试使用公开 DNS 返回的 IP 固定连接，并保持 TLS 主机名与证书校验；生产防护没有放宽。部署时应修复 DNS/代理路由。

参考生成/继续编辑支持管理员选择 OpenAI `/images/edits` 的 multipart `image[]` 或 JSON `images` 传输；Chat 和 Gemini 适配器会按各自多模态协议发送参考图。兼容 Images 供应商的编辑字段仍需以服务商文档为准，默认关闭，须确认该模型的接口与限制后启用。OpenAI 格式依据：[Images edit reference](https://developers.openai.com/api/reference/resources/images/methods/edit)。

回归覆盖额度/幂等/并发赞助、未知结果与恢复凭据、部分结果、私有图片权限、资源版本、模板字面替换与接口 schema。浏览器验收使用明确标记的确定性图片供应商及临时 SQLite/miniredis，验证真实页面、HTTP 路由与数据库写链路，不代表第三方编辑功能已验收。
