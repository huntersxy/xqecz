### 小泉动漫二创站
- 定义：项目名称 xqecz 的全称，指用户上传和浏览二次创作内容（图片、视频、图文、链接）的动漫主题网站，包含评论、投票和管理后台功能。
- 别名：xqecz、动漫二创站

### 共享上传目录
- 定义：NestJS API 与 Go Worker 共同使用的文件存储目录，通过 UPLOAD_DIR 环境变量配置，确保两端对同一绝对路径的文件读写一致。单一配置源为 packages/api/.env。
- 别名：UPLOAD_DIR、uploads

### 推荐刷新
- 定义：由 NestJS API 主导的内容推荐算法执行流程：读取 MySQL approved 内容 → 组装 RecommendItem[] 经 gRPC RefreshRecommend 调用 Worker 纯打分 → 将 ScoredItem[] 结果原子写入 Redis ZSet recommend:hot。
- 别名：refresh-recommend、recommend refresh

### 无状态 Worker
- 定义：Go Worker 的设计约束，不直连 MySQL/Redis，不含 cron 调度，只做 gRPC 无状态计算，数据通过 gRPC 从 NestJS 传入、结果回传 NestJS 落库或写缓存。
- 别名：stateless worker、worker 无状态

### 软删除
- 定义：所有删除操作写 deleted_at 字段而非物理删除，Entity 声明 @DeleteDateColumn()，TypeORM 查询自动附加 WHERE deleted_at IS NULL 条件，业务代码无需手动过滤。
- 别名：soft delete、deleted_at

### 降级优先
- 定义：外部依赖（Tinify/S3/Worker）缺失时的处理策略，gRPC 永不返回 rpc error，只返回 success=false + error 文本，保证服务可用性。
- 别名：graceful degradation、降级

### 归档
- 定义：旧后端仓库（xqecz-golang、xqecz-nodejs、xqecz_frontend）迁移至 monorepo 后，原仓库整体移至 D:/xqecz/archive/ 目录保留完整 git 历史，不再作为工作区的一部分。
- 别名：archive、已归档
