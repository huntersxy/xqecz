根目录作为 monorepo 入口，通过 `pnpm-workspace.yaml` 声明 `packages/*` 与 `proto` 为工作区包；`package.json` 定义跨包脚本（`dev`/`build`/`start` 经 `concurrently` 并发启动 api、worker、fe），并通过 `pnpm --filter ./packages/api` 和 `pnpm run worker:run` 分别调用子包命令。`scripts/run-worker.mjs` 负责从 `packages/api/.env` 注入 `UPLOAD_DIR` 等环境变量给 Go worker，实现单一配置源。`.gitignore` 统一忽略各包产物（`dist/`、`*.exe`、`proto/gen/`、`archive/`）。`plan.md` 记录六阶段实施过程与架构演进（含 §2.8 将 worker 改为无状态、不直连 DB/Redis 的关键纠正），`AGENTS.md` 作为开发者权威指南，描述 gRPC 接口表、推荐链路、修改流程与核心约束。依赖方向：根 → packages/{api,worker,frontend,proto}，worker 与 api 仅通过 proto 定义的 gRPC 通信，无其他耦合。
