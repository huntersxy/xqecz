- 所有跨服务共享配置（如 UPLOAD_DIR）集中在 `packages/api/.env`，worker 通过 `scripts/run-worker.mjs` 启动时读取该文件注入环境变量，避免多配置源。
- gRPC 字段统一使用 snake_case，client 侧通过 `loader: { keepCase: true }` 保持与 Go worker 一致，禁止 camelCase 混用。
- 外部依赖（Tinify/S3/Worker）缺失时一律降级返回 `success=false` + error 文本，gRPC 永不抛出 rpc error，由 api 层处理降级逻辑。
- TypeORM 实体使用软删除（`@DeleteDateColumn()`），业务查询无需手动过滤 `deleted_at IS NULL`，由 TypeORM 自动附加。
- bigint 主键与 Redis ZSet 成员比对前必须 `String()` 归一化，避免数字与字符串类型不一致导致 Map 查找失败。
